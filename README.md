# 💻 Terminal Portfolio

A personal portfolio deigned to look and feel like an Ubuntu terminal.
You can explore it by interacting with a command line interface.

🚀 **Live demo:** https://tijasp.dev/

## 🔎 Preview
![Website screenshot](https://github.com/tijasp/Terminal-Portfolio/blob/main/screenshots/screenshot.png?raw=true)

## ✨ Features

-   **Terminal inspired interface** - A minimalist design inspired by Ubuntu terminal
-   **Interactive command system** - Navigate using commands
-   **Multilingual support** - Switch between English and French

## ⚙️ Used technologies

-   **HTML5** - Page structure.
-   **CSS3** - Styling and terminal layout.
-   **JavaScript** - Terminal interactions and command management.
-   **Responsive Design**

## 🚀 Getting started
#### 1. Clone the repository

`git clone https://github.com/tijasp/Terminal-Portfolio.git`

#### 2. Open the project

Navigate to the project directory:
`cd Terminal-Portfolio`

#### 3. Run the project

Use a local development server such as the Live Server extension in Visual Studio Code.
